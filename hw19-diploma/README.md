Проектная работа - Task Management System с авторизацией и ролями
пользователи создают проекты и задачи, добавляют комментарии к задачам, 
а данные защищены JWT и ролями.

Архитектура:

Фронт: Thymeleaf

Backend: 
 Spring MVC
 DB: PostgreSQL + Spring Data JPA + Flyway
 Docker: БД + Kafka + Kafka Manager + Zookeeper + приложение 
 API: REST 
 Кэширование пользователей
 Resillience4J + Retry для методов сервисов 
 Spring Security: Jwt  + PreAuthorize на методах сервисов по модификации данных, роли (USER, ADMIN)
 Spring Boot Actuator
 Аудирование CRUD над проектамми, задачами, пользователями в БД (без интерфейса). Аудирование реализовано через брокер сообщений Kafka.
 Юнит тесты контроллеров

Функциональные возможности:

Для пользователей:

  - Регистрация и авторизация (JWT)
  - CRUD проектов и задач
  - Создание задач пользователям, редактирование своих задач
  - Просмотр задач по проектам
  - Статусы задач (TODO, IN_PROGRESS, DONE, DEFERRED)
  - Просмотр всех проектов и задач

Для администраторов:

Управление пользователями - CRUD
